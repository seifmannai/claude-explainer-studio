# Animation notes (our own words; sources linked, not copied)

Source idea: github.com/vibe-motion/skills, "disney-animation-rule-skill" (no licence file, so nothing copied).

- Treat the 12 principles as a checklist per ACTION, not per film: for each move ask which of anticipation,
  squash/stretch, follow-through, arcs, slow-in/out, secondary action and exaggeration it uses. A move that uses
  fewer than three reads as mechanical.
- Design the pose first (clear silhouette), then the timing, then the in-betweens. Timing changes meaning more
  than the pose does: the same pose change in 3 frames is a shock, in 20 frames it is sadness.
- Exaggerate about twice as far as feels right in a still; in motion it reads as normal.
- Holds are "moving holds": keep 1-3 % of drift so the character stays alive while the pose reads.
- Jumps and falls: stretch along the velocity, squash on contact, volume stays constant.
